# V1.0 attribution and asset policy

LUNAR V1.0 has an original interface, navigation, guide prose, palette, SVG bearings, observation project flow and connected-base tool. It does not present the upstream welcome cards, screenshots, mission narratives, mission photos or vehicle showcases.

Substantial rendering, camera and browser geometry/planning algorithms are adapted from daniel27-space/lunar-navigator under Apache 2.0: https://github.com/daniel27-space/lunar-navigator . NOTICE and LICENSE preserve the required attribution. Source-derived functionality is not claimed as an independent LUNAR invention.

NASA-origin LOLA/LROC/Blue Marble inputs and factual mission-coordinate source links remain. The factual catalog retains names, coordinates, dates, agencies and URLs; non-NASA artistic assets and copied descriptions are removed from the runtime app. Original upstream documentation and source pipeline are retained for provenance, visibly separated from the LUNAR README.

The original LUNAR Python core and archived studies originate in the supplied Atlas v0.2. V1 changes new single-site solar calculations to include a documented Earth-occultation approximation. Those changes do not rewrite archives or waive failed validation.

Dependency licenses are in THIRD_PARTY_LICENSES.txt. OpenAI Codex assisted the V1 implementation and documentation. Upstream assistance disclosures remain in its archival documentation.
