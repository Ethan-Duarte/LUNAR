# Contributing

Use a separate branch and run the checks in TESTING.md. Keep scientific changes distinguishable from display changes. Preserve failed validation evidence and document data, frames, criteria, dates and sampling assumptions. Do not change a threshold simply to obtain a pass.

Keep Basic accessible and preserve observations and projects across tools. Use original interface text/assets, retain dataset credits and follow NOTICE and dependency licenses. See ARCHITECTURE.md and ENGINEERING.md for the current implementation.
